# tree-sitter-cleave

[Tree-sitter](https://tree-sitter.github.io/tree-sitter/) grammar for the [Cleave](https://github.com/cleave-lang/cleave) programming language (`.cv` files).

Cleave is a programming language for building blockchains from scratch. This repo provides the tree-sitter grammar that editors and tooling use to parse and highlight Cleave source.

## Status

Initial scaffold. Tracks the reference grammar at [`cleave-lang/cleave/spec/grammar.ebnf`](https://github.com/cleave-lang/cleave/blob/main/spec/grammar.ebnf) plus the planned module-body productions. Iterates as the reference grammar grows.

| Production | Grammar | Highlights |
|---|---|---|
| Chain block | ✅ | ✅ |
| Module bodies | ✅ | ✅ |
| Protocol declarations | ✅ | ✅ |
| Effects, slash_on | ✅ | ✅ |
| Functions, blocks, statements | ✅ | ✅ |
| Expressions (binary, unary, call, member, path, percent) | ✅ | ✅ |
| Type expressions, generics, set literals | ✅ | ✅ |
| Comments | ✅ | ✅ |

## Build

```bash
npm install              # installs tree-sitter-cli
npm run generate         # generates src/parser.c
npm test                 # runs the corpus tests
```

`npm run parse <file.cv>` parses a file and prints the syntax tree.

## Editor integration

### Neovim (via nvim-treesitter)

Add a `parser_config` entry pointing at this repo. Once tree-sitter-cli generates the parser, nvim-treesitter can install it. The highlights query in `queries/highlights.scm` uses standard tree-sitter capture names so any modern theme picks them up.

### Helix

Add an entry to your Helix `languages.toml`:

```toml
[[language]]
name = "cleave"
scope = "source.cv"
file-types = ["cv"]
roots = []
comment-token = "//"
indent = { tab-width = 4, unit = "    " }

[[grammar]]
name = "cleave"
source = { git = "https://github.com/cleave-lang/tree-sitter-cleave", rev = "main" }
```

Then `hx --grammar fetch && hx --grammar build`.

### Zed

Submit a language extension that points at this grammar. Zed's extension system reads tree-sitter grammars directly.

## Layout

```
tree-sitter-cleave/
  grammar.js              # the grammar definition (the source of truth)
  queries/
    highlights.scm        # syntax highlight capture queries
  test/
    corpus/               # tree-sitter test fixtures
      chain.txt
      module.txt
  package.json
  LICENSE                 # Apache-2.0
```

`src/` (parser.c, grammar.json, node-types.json) is generated by `tree-sitter generate` from `grammar.js`. Whether to commit it is the standard tree-sitter-grammar tradeoff; this repo errs toward committing it so editors that fetch by tag work without a build step.

## Contributing

This grammar tracks [the Cleave language reference](https://github.com/cleave-lang/cleave/tree/main/spec). When the reference grows, this grammar follows.

PRs should:

1. Update `grammar.js` to cover the new production.
2. Add test fixtures in `test/corpus/`.
3. Run `npm run generate && npm test`.
4. Update `queries/highlights.scm` if the new production introduces capture-worthy nodes.
